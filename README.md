Vice Coast Cover Studio — an offline web app that turns any photo and caption into multi-panel GTA-style poster cover art with a Vice City sunset or neon grade, exported as a PNG to share. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

Upload your own photos (or use the three built-in samples), pick from six poster layouts — Hero + 3, nine-panel grid, trio strip, duo split, full bleed, tilted snapshots — crop and position each panel by dragging, edit the title and tagline in bold poster lettering, apply one of five colour grades, and export in 1:1, 4:5, 9:16 or 16:9. Everything runs offline in the browser; photos never leave your machine. Original artwork only — no Rockstar Games logo, artwork or fonts; lettering is Anton and Pacifico under the SIL Open Font License.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To hand in the entry, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
